# Laboratorios de relatorios financeiros

As implementacoes sao opt-in e nao alteram o gerador Python existente.

- R (base R): consolida totais por categoria a partir de colunas category e amount. Teste: Rscript labs/r/test_expense_summary.R
- COBOL (GnuCOBOL): calcula total de uma fatura com percentual de tributo de 0 a 100, usando casas decimais. Teste: sh labs/cobol/test_invoice_total.sh

Dados do laboratorio sao ficticios. Nunca utilize esses calculos como regras tributarias oficiais.
